# Agent Writing evaluation boundary

Deterministic mechanical gates use the versioned default JSON-pattern grader for required source literals, exact domain terms, concrete fixture exclusions, and schema-valid case structure only. A failed critical mechanical gate is non-overridable.

Semantic writing quality is adoption evidence. Fresh matched with-Skill and No-Skill outputs are compared by a blind judge that must quote or reference output evidence for branch behavior, disclosure, grounding, relevance, environment handling, and completion. Sampled human review checks contextual appropriateness and catches rubric gaps.

Trigger evaluation remains separate and uses the exact ordered lifecycle evidence from the shared v2 contract. Component evaluation keeps one neutral task while shared orchestration removes only Writing Foundation for the ablated arm.

Generated runs, judgments, reports, and review notes remain uncommitted.
