# Skill Writing evaluation boundary

Versioned role, component, outcome, and trigger cases are host-neutral. The
three component cases use the shared test-only Adapter seam to remove exactly
one declared dependency edge; production package failures remain separate.

Deterministic checks cover mechanics only: schema-valid cases, exact canonical
names, required literals, artifact existence, and resolvable files or pointers.
They do not parse natural-language quality or treat valid mechanics as
behavioral proof.

Semantic behavior uses fresh matched Skill and No-Skill sessions. Blind model
judgment must cite output evidence for justification, contract quality,
dependency contribution, and verification honesty. Trigger selection is
evaluated separately from output quality, and sampled human review checks every
failure plus passing samples.

Generated runs, judge payloads, reports, viewers, and workspaces remain
uncommitted.
