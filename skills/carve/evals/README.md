# Carve planning evaluations

The versioned definitions under Carve, Slice Plan, and Ticket Scope cover the
ordinary and hardened planning roles, each declared dependency edge, the
complete public Carve outcome, canonical-only activation, and private
dependency false activation. Hardened pressure cases cover stable regeneration,
split/combine lineage, prefactoring, expand-contract groups, overlapping
collisions, invalid graphs, and needs-decision publication refusal.

Run treatment and No-Skill arms in matched fresh sessions with the same prompt,
files, host, model, tools, timeout, and repetition. Component cases replace
only one declared dependency load through the suite's test Adapter. Package
closure cases remove production dependencies separately and must fail before
Skill execution with the exact canonical name.

Deterministic checks cover mechanics only: plan schema, coverage-ledger
completeness, stable identity and cumulative lineage, migration-phase ordering,
graph references, prerequisite consumption, blocker and consumed-output
agreement, acyclicity, transitive minimality, frontier derivation,
needs-decision write refusal, exact Skill lifecycle evidence, artifact
existence, tracker read-back, and forbidden writes. Semantic ticket
independence, natural seams, genuine prerequisites, source-faithful exclusions,
and publication quality use evidence-bearing blind model judgment plus sampled
human review. Do not grade those meanings with a brittle natural-language regex
or parser.

Measure trigger selection separately from output quality. A matched control is
valid only when pre-execution inventory and lifecycle evidence prove that
Carve, Slice Plan, Ticket Scope, and their transitive dependencies are absent.

Generated plans, model runs, judge payloads, tracker sandboxes, reports, and
viewer output remain uncommitted under ignored evaluation output directories.
Version prompts, source fixtures, schemas, validators, and reusable graders.
Do not run a paid or credentialed campaign as part of static validation.
