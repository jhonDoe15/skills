# Evidence and validation

Use this fallback only when repository authority leaves proof conditions
uncovered.

- Tie each claimed behavior to an observable check at a public boundary.
- Match evidence strength to risk and change size.
- Include expected failure behavior and regression coverage where applicable.
- Separate deterministic mechanical checks from semantic judgment.
- Name the command, artifact, or observation that would provide evidence. Leave
  execution and the pass or fail decision to the caller.
