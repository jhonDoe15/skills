# Simplicity and reuse

Use this fallback only when repository authority leaves solution shape
uncovered.

- Choose the smallest solution that satisfies the present requirement.
- Reuse a stable responsibility, not merely similar-looking code.
- Prefer local duplication over a speculative shared abstraction.
- Add indirection only when it hides meaningful change or enforces a contract.
- Remove planned flexibility that has no current consumer or requirement.
