# Sources

This file records provenance for maintainers. It is not part of the skill's execution path.

## Theo Browne video

[My AGENTS.md & SKILLS.md Breakdown (Don't copy
them)](https://www.youtube.com/watch?v=e1snsuY4lTI) informed the failure-audit loop, personal tone,
README-versus-agent-file distinction, trigger-oriented skill descriptions, intent-based skill
splitting, communication focus, and representative behavioral testing.

The skill follows the video's central warning: use the method, not another person's configuration.

## Local design session

The session added:

- distinct private, repository, service, component, environment, and reference scopes
- Keep/Move/Delete migration maps with a destination or reason for every removal
- subject-scoped progressive disclosure and explicit pointer triggers
- the distinction between Markdown pointers and automatic loading
- preservation checks for ownership, compatibility, workflow, safety, and environment facts
- constraint-based environment naming rather than editor or product naming
- pressure tests for private files, project files, and extracted workflows
