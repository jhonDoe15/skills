# Writing Foundation evaluation boundary

Deterministic mechanical gates use the versioned default JSON-pattern grader for the exact source-owned `DAG frontier` term, the exact `{"maxAttempts":3}` literal, concrete duplicate removal, and schema-valid case structure only. A failed critical mechanical gate is non-overridable.

Coverage, grounding, unresolved-owner handling, relevance, pruning quality, audience independence, and justified completion are semantic adoption evidence. A blind judge must quote or reference output evidence for each score, followed by sampled human review of fresh matched outputs.

Exact lifecycle evaluation remains separate under the shared v2 contract. Generated runs, judgments, reports, and review notes remain uncommitted.
